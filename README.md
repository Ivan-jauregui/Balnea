Balnea — API REST para Gestión y Reserva de Balnearios
​Balnea es una solución backend desarrollada en Java con Spring Boot diseñada para digitalizar la gestión, reserva y administración de balnearios. La plataforma permite a los dueños de balnearios administrar sus instalaciones, tarifas estacionales, sectores y servicios (carpas, sombrillas), mientras ofrece a los usuarios un sistema flexible para consultar disponibilidad y realizar reservas.

​🚀 Características Principales

​Gestión de Balnearios: Registro de instalaciones con coordenadas para mapas, descripción, precios base, fechas de temporada (apertura/cierre) e imágenes.
​Mapeo de Sectores y Filas: Configuración flexible de filas de carpas/sombrillas y esquemas de distribución en la playa.
​Tarifas Dinámicas: Configuración de múltiples esquemas de precios según la temporada o la ubicación de las filas.
​Amenities y Servicios: Asociación de comodidades (piscina, estacionamiento, vestuarios, wifi) a cada establecimiento.
​Gestión de Usuarios y Roles: Autenticación y autorización basada en roles (Clientes, Dueños/Administradores de Balnearios).
​Sistema de Valoraciones: Reseñas y comentarios de los clientes sobre los establecimientos.
